# Blackh()le radiation
This is a game where the entire universe has been split apart and destructed by a supermassive blackhole. You have to use Hawking radiation principles to collect the radiation and rebuild the universe , bit by bit.  (do not try to touch the blackhole >: ] )

## Controls
core gameplay : Click on things which fly on the screen (its that simple) :D 
Level selector: select the levels by clicking on the icons ( Do by numerical order to get a chronological storyline which is coherent thanks ;>) )
(ps. sometimes you would have to hover over things to click on them to transaport to next scene or so )
